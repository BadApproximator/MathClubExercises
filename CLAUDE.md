## О проекте

Статический сайт математического клуба «Матклуб» на Astro 7 и TypeScript (strict). Полный план, дизайн и принятые решения — в [docs/PLAN.md](docs/PLAN.md); перед любой задачей сверяйся с ним, особенно с разделом «Пошаговый план» и «Открытые вопросы» (там зафиксированы решения).

Текущее состояние: выполнен шаг 1.1 (пустой каркас). Есть только заглушка `src/pages/index.astro` и `public/favicon.svg`.

Используй краткие ответы, без лишнего кода -- только ключевая информация.

Перед рефакторингом и работой с кодом всегда читай файл @spec.md.

## Команды

```sh
npm install
npm run dev      # localhost:4321
npm run build    # astro check && astro build → dist/
npm run preview  # просмотр собранного dist/
npm run check    # только astro check (типы и шаблоны)
```

Тестов и линтера пока нет. Проверка изменений — `npm run build` (должно быть 0 ошибок `astro check`).

## Окружение и версии

- Node ≥ 22.23.4 (`.nvmrc` = 22, `engines` в `package.json`) — это минимум для Astro 7.
- `typescript` закреплён на `^6`: `@astrojs/check` не поддерживает TypeScript 7, с ним `npm install` падает на peer-зависимостях. Не обновлять до 7, пока `@astrojs/check` не добавит поддержку.
- Prettier в проекте **не используется** — решение владельца, не добавлять его обратно. Prettier в `package-lock.json` — транзитивная зависимость `@astrojs/check`, это нормально. Форматирование `.astro` при сохранении делает расширение Astro в VS Code (`.vscode/`).

## Целевая архитектура (из плана, ещё не реализована)

- **Контент без БД:** одно занятие — одна папка `src/content/sessions/NNN-slug/` с `index.mdx` и картинками рядом. Справочник тем — `src/content/topics.yaml` (5 тем, у каждой свой цвет). Поля frontmatter проверяются схемой коллекции контента Astro; неверное поле должно ломать сборку с понятным сообщением.
- **Формулы:** `remark-math` + `rehype-katex`, рендер при сборке, ошибка LaTeX ломает сборку.
- **Блоки занятия (MDX-компоненты):** `<Problem kind="main|homework">`, `<Hint>`, `<Solution>` (сворачиваются без JS, через `<details>`), Замечание, Теорема, Рисунок с нумерацией.
- **Стили:** обычный CSS с переменными, без фреймворков. Светлая «бумажная» и тёмная темы; тема по умолчанию из системы, переключатель запоминает выбор, без мигания при загрузке. Палитра и шрифты (Literata, Inter, KaTeX, JetBrains Mono) — в `docs/PLAN.md`.
- **JS в браузере** только «островками» там, где он нужен (переключатель темы, поиск и т. п.); страницы по умолчанию без JS.
- **i18n:** стартуем на русском, но закладываем многоязычность — надписи интерфейса в одном словаре, встроенная маршрутизация Astro (`/` — русский, позже `/en/`, `/sr/`), перевод занятия — соседний `index.en.mdx`.
- **Страницы:** `/`, `/sessions/`, `/sessions/NNN-slug/`, `/topics/<topic>/`, `/about/`, 404. Адреса латиницей.
- **Деплой:** Cloudflare Pages (шаг 1.2), сборка `npm run build`, вывод `dist/`.
