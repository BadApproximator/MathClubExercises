# Матклуб

Сайт математического клуба: каждое занятие с условиями задач, разборами и литературой. План разработки — в [docs/PLAN.md](docs/PLAN.md).

Сделан на [Astro](https://astro.build) и TypeScript.

## Запуск

Нужен Node.js 22.23.4 или новее (версия указана в `.nvmrc`).

```sh
npm install
npm run dev
```

Затем открой <http://localhost:4321>.

## Команды

| Команда                | Что делает                                                    |
| ---------------------- | ------------------------------------------------------------- |
| `npm install`          | Устанавливает зависимости                                     |
| `npm run dev`          | Запускает сайт локально на `localhost:4321` с автообновлением |
| `npm run build`        | Проверяет типы (`astro check`) и собирает сайт в `dist/`      |
| `npm run preview`      | Показывает собранный сайт из `dist/`                          |
| `npm run check`        | Только проверка типов и шаблонов Astro                        |

## Структура папок

```text
.
├── docs/              ← план и документация проекта
├── public/            ← файлы, которые копируются как есть (favicon.svg)
├── src/
│   └── pages/         ← страницы сайта; путь к файлу = адрес страницы
│       └── index.astro
├── .vscode/           ← рекомендуемые расширения и форматирование при сохранении
├── astro.config.mjs   ← настройки Astro
├── tsconfig.json      ← TypeScript в строгом режиме
└── package.json       ← зависимости и команды
```

## Редактор

В VS Code при открытии проекта появится предложение поставить расширение Astro. С ним файлы `.astro` форматируются при каждом сохранении.
